# 회원사 설문 랜딩 페이지

협회가 회원사에 배포할 링크의 도착 지점이다. GitHub Pages로 무료 호스팅한다.

## 배포 순서

### 1) Google Form 먼저 만든다
`실증및설문설계/설문지/협회회원사/회원사_GoogleForm_문항정의서.xlsx` 를 보고 그대로 만든다.
문항 제목 끝의 `[필드코드]`를 **반드시 그대로** 넣어야 집계가 자동으로 된다.

### 2) 두 값을 알아내 index.html에 적는다
```js
var FORM_URL  = "";   // 폼 → 보내기 → 링크(…/viewform)
var ENTRY_SRC = "";   // 폼 → 점 3개 → 미리 채워진 링크 만들기 →
                      // Q7(안내받은 경로)에 아무 값이나 입력 → 링크 생성 →
                      // 주소에서 entry.XXXXXXXXX 부분
```

### 3) GitHub Pages 배포
1. GitHub에 **공개 저장소**를 새로 만든다 (예: `reg-survey`)
2. 이 폴더의 `index.html` · `privacy.html` 만 올린다
3. Settings → Pages → Source: `main` 브랜치 / `/ (root)`
4. 몇 분 뒤 `https://<계정>.github.io/reg-survey/` 로 열린다

> **저장소에 조사 대장·연락처·회신 파일을 절대 올리지 말 것.**
> 공개 저장소라 누구나 볼 수 있다. 이 폴더의 두 HTML만 올린다.

### 4) 협회별 링크 만들기
`?src=` 뒤에 협회 코드를 붙이면 유입 경로가 폼에 자동 기록된다.

| 협회 | 배포 링크 |
|---|---|
| 한국인공지능협회 | `…/reg-survey/?src=koraia` |
| 코리아스타트업포럼 | `…/reg-survey/?src=kstartup` |
| 한국핀테크산업협회 | `…/reg-survey/?src=korfin` |
| 한국AI·로봇산업협회 | `…/reg-survey/?src=korearobot` |

만든 링크는 설문대상자 통합 파일 `5.회원사 배포 관리` 시트에 기록한다.

### 5) .env에 주소를 넣는다
```
LANDING_URL=https://<계정>.github.io/reg-survey/
```
넣지 않으면 회원사 안내문 발송이 차단된다(본문이 완성되지 않으므로).

## 미리 보기
브라우저로 `index.html` 파일을 직접 열면 된다. 서버가 필요 없다.
`FORM_URL`이 비어 있으면 버튼이 "설문 준비 중입니다"로 표시된다.

## 유의사항
- **차단 대비** : 일부 공공기관·협회 망에서 `github.io` 가 막히는 사례가 있다.
  안내문에 폼 직접 주소를 함께 적어 두는 것이 안전하다.
- **개인정보처리방침** : `privacy.html` 은 설문 고지 의무를 위한 것이자,
  나중에 OAuth 방식으로 전환할 때 구글이 요구하는 URL로도 쓸 수 있다.
- **다크 모드** : 두 페이지 모두 시스템 설정을 따라간다.
